# FE Skills Platform

This repository is a front-end practice platform used to improve React and TypeScript skills.

The app is intentionally built as a small interactive playground for refining component design, form handling, accessibility, and UI behavior.

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

The page reloads when you make edits.

### `npm test`

Launches the test runner in interactive watch mode.

### `npm run build`

Builds the app for production to the `build` folder.

The build is minified and the filenames include hashed content.

### `npm run eject`

**Note: this is a one-way operation. Once you `eject`, you can’t go back.**

## Notes

- The app is used as a hands-on experiment for front-end skills, including component patterns, validation, and accessibility.
- It is built with Create React App and TypeScript.
